Report: Temporal Attention-Based LSTM Model Evaluation

1. Overview

This experiment evaluates a baseline LSTM model and an attention-based LSTM model for time-series prediction. Model performance is measured using RMSE and MAE. We analyze interpretability by examining average temporal attention weights across test samples.

2. Training Summary

2.1 Baseline LSTM

Training epochs: 10

Final training loss: ≈ 5.82 × 10⁻⁴

Evaluation metrics:

RMSE: 0.0237

MAE: 0.0193

The baseline model converges smoothly and achieves low prediction error.

2.2 Hyperparameter Optimization (Optuna)

Optimized parameter: Number of LSTM units

Best configuration:

Units = 90

Best validation objective value: 0.06419

This shows that larger hidden representations improved validation performance during tuning.

2.3 Attention-Based LSTM

Training epochs: 20

Final training loss: ≈ 0.0018

Evaluation metrics:

RMSE: 0.0604

MAE: 0.0510

Although attention improves interpretability, the attention model shows higher error compared to the baseline, suggesting possible over-parameterization or suboptimal attention weighting.

2.4 Rolling LSTM Evaluation

Rolling RMSE: 0.1271 ± 0.0079

This higher error reflects the increased difficulty of rolling multi-step forecasting.

3. Temporal Attention Analysis

3.1 Observed Attention Values (from plot)

The attention distribution over time steps shows:

Time steps 0–20: Attention ≈ 0.00–0.005. Minimal contribution to predictions.

Time steps 22–35: Sharp rise in attention. Peak attention ≈ 0.072–0.074 at about time step 28.

Time steps 36–48: Gradual decay. Stabilizes around 0.018–0.020.

3.2 Interpretation

The model focuses strongly on recent past observations, especially around time step 28. Early time steps contribute very little, indicating that the model mainly relies on short-to-medium temporal dependencies. The attention decay after the peak suggests that very recent steps become less relevant over time. This behavior aligns with many real-world temporal processes where mid-range historical context has the most predictive power.

4. Comparative Performance Summary

Model Type   RMSE       MAE        Interpretability  
Baseline LSTM    0.0237     0.0193     Low  
Attention LSTM   0.0604     0.0510     High  
Rolling LSTM     0.1271     —         Medium  

5. Key Findings

The baseline LSTM outperforms the attention LSTM in raw accuracy. The attention mechanism provides clear temporal interpretability, highlighting important time steps. Performance drops with the attention model suggests a need for stronger regularization and a possible mismatch between attention complexity and dataset size. Rolling forecasts significantly increase error, confirming accumulated uncertainty.

6. Conclusion

While the attention-based LSTM does not outperform the baseline in terms of RMSE and MAE, it offers valuable insights by identifying key temporal regions. For applications that prioritize model interpretability, attention mechanisms are useful. However, for pure predictive accuracy, the baseline LSTM remains better in this setup.
